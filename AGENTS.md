# Repository conventions

Workflow figures follow `docs/WORKFLOW_STYLE.md`, the shared MP nodal contract.
Read it before editing figures, generators, exports or embeds.

Public documentation lives exclusively in `docs/user-guide/`. Other files under
`docs/` include local manuscripts and research results: do not stage, publish,
package, move or rewrite them as part of documentation maintenance.
Keep analysis data and study-specific test manifests outside the repository.
